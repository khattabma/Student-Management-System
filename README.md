# 🎓 Student Management System

A web-based Student Management System built with Flask, Python, SQLite, HTML, and CSS.

## 📌 Description

This project allows users to manage student records through a simple web interface.

Users can:

- Register an account
- Login securely
- Add new students
- View all students
- Edit student information
- Delete students
- Logout securely

---

## 🚀 Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/khattabma/Student-Management-System.git
```

Go to the project folder

```bash
cd Student-Management-System
```

Install Flask

```bash
pip install flask
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
