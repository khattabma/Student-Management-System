About Student Management System

A modern web application built to simplify student management.

🎓 Project Overview

Student Management System is a web application developed using Python, Flask, SQLite, HTML, CSS, and Bootstrap.

The application allows users to securely register, log in, manage student records, upload student photos, search students, edit information, delete records, and export data.

🚀 Main Features

  • ✅ Secure User Registration
  • 🔐 Secure Login Authentication
  • 👨‍🎓 Add Students
  • ✏ Edit Student Information
  • 🗑 Delete Students
  • 🔍 Search Students
  • 📷 Upload Student Photos
  • 📄 Export Student Data to CSV

💻 Technologies Used

• Python
• Flask
• SQLite
• HTML5
• CSS3
• Bootstrap 5
• Font Awesome
