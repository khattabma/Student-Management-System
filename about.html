Student Management System

This project is a web-based Student Management System developed using Python, Flask, SQLite, HTML, and CSS.

The system allows users to register, log in securely, add students, search, edit, delete, and manage student records easily.

This project was created for educational purposes to demonstrate CRUD operations, authentication, session management, and database integration using Flask.
